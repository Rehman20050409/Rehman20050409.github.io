Turtle

A tiny programming language for drawing, in the spirit of Logo, with a playground that redraws as you type.

I wrote every stage by hand with no libraries: a tokenizer, a recursive-descent parser and a tree-walking interpreter. It has loops, conditions, maths and your own commands with parameters and recursion, which is enough to draw fractal trees and snowflakes.

Mistakes get an error message with a line number, and a program that would run forever is stopped instead of freezing the page.

  • JavaScript
  • Canvas
  • Parsing
  • No dependencies

Split

A full-stack web app for sharing costs with flatmates. Create a group, invite people with a code and add what you paid for. It keeps everyone's balance and works out the fewest payments needed to settle up.

The server is Node.js with no web framework, and the data lives in a hosted SQLite database. Money is stored as whole pence so rounding never drifts.

Passwords are hashed, logins are rate limited, and every request checks that you belong to the group you are asking about.

  • Node.js
  • SQLite
  • Accounts and sessions
  • Deployed on Render

Scratch Reader

Drop in a Scratch project and read its blocks as Python-style code, along with a breakdown of what the project is made of.

A Scratch file is really a zip archive, so the reader parses the zip format by hand, unpacks it with the browser's built-in decompression, then follows Scratch's table of linked blocks to rebuild each script.

Everything runs in the browser, so the file never leaves your computer. I checked it against 26 of the Scratch team's own test projects.

  • JavaScript
  • File formats
  • Code generation
  • No dependencies

Sort Sounds

Watch and hear sorting algorithms. Every comparison plays a note, pitched by the height of the bar, so bubble sort and merge sort each end up with their own tune.

Each algorithm is written as a generator, a function that can pause after every step. That keeps the sorting code looking like the textbook version, with no drawing or sound mixed in, and lets the page run it at any speed.

It counts the comparisons and writes each algorithm needs, so you can see as well as hear why some are faster.

  • JavaScript
  • Algorithms
  • Web Audio
  • Canvas

Repo Time-lapse

Type any public GitHub repository and watch it grow from its first commit to today. Every file is a dot and every folder a branch, drawn as a tree that fills out over time.

It reads the project's history live from GitHub's API. That API allows only 60 requests an hour without signing in, so it picks ten moments across the history and fetches just the pages that hold them.

All the files that ever existed are laid out once, in a circle, so nothing jumps around as time moves: files only fade in and out.

  • JavaScript
  • GitHub API
  • Tree layout
  • Canvas

Is it raining in Glasgow?

A live answer to Glasgow's most asked question: a giant yes or no, with this year's rain in numbers. When it is raining, it rains on the page too.

It pulls live and historical weather from a free weather service and works out the wet days, the longest dry and wet spells and the wettest day of the year so far.

The record of past days lags a little behind, so the page merges it with a fresher forecast feed, and it takes today's date from Glasgow, not from the visitor's clock.

  • JavaScript
  • Weather API
  • Data
  • No dependencies

Air Racket

A 3D padel game where your phone is the racket and a laptop or TV is the court. Swing harder and the shot is faster and flatter; swing a forehand or a backhand and the ball goes a different way.

The phone picks out each swing from the spike in its motion sensor, and the ball follows real gravity and bounce, including coming back off the glass behind you. Phone and screen connect directly to each other, so there is no game server and very little delay.

There is 1 v 1 and 2 v 2 against the computer at three difficulty levels, an adjustable ball machine, and a one-phone mode you can mirror to a TV. It also plays from the keyboard.

  • JavaScript
  • Three.js
  • Motion sensors
  • WebRTC
