Turtle

A tiny programming language for drawing, in the spirit of Logo, with a playground that redraws as you type.

I wrote every stage by hand with no libraries: a tokenizer, a recursive-descent parser and a tree-walking interpreter. It has loops, conditions, maths and your own commands with parameters and recursion, which is enough to draw fractal trees and snowflakes.

Mistakes get an error message with a line number, and a program that would run forever is stopped instead of freezing the page.

  • JavaScript
  • Canvas
  • Parsing
  • No dependencies

Split

A full-stack web app for sharing costs with flatmates. Create a group, invite people with a code and add what you paid for. It keeps everyone's balance and works out the fewest payments needed to settle up.

The server is Node.js with no web framework, and the data lives in a hosted SQLite database. Money is stored as whole pence so rounding never drifts.

Passwords are hashed, logins are rate limited, and every request checks that you belong to the group you are asking about.

  • Node.js
  • SQLite
  • Accounts and sessions
  • Deployed on Render

Scratch Reader

Drop in a Scratch project and read its blocks as Python-style code, along with a breakdown of what the project is made of.

A Scratch file is really a zip archive, so the reader parses the zip format by hand, unpacks it with the browser's built-in decompression, then follows Scratch's table of linked blocks to rebuild each script.

Everything runs in the browser, so the file never leaves your computer. I checked it against 26 of the Scratch team's own test projects.

  • JavaScript
  • File formats
  • Code generation
  • No dependencies
